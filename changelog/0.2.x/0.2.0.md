# 0.2.0 — 2026-10-26

## Added

- Add the grantsgov-guide skill resource for funding shortlists, eligibility and deadline review, and application requirements.
- **Agent Plugins** root manifests support installation alongside the existing client overlays.

## Changed

- **`grantsgov_list_reference`** pages the complete filtered list with a default of 50, cap of 100, deterministic agency ordering, and executable continuation arguments. ([#23](https://github.com/cyanheads/grantsgov-mcp-server/issues/23))
- **Development tooling** syncs framework skills, packaging validation, dependency-audit classification, and the bug-report environment form; MCPB cleanup retains SDK skill runtime modules while removing dependency guidance and build-only files.
- **Docker** uses Bun 1.4.3 → 1.4.4 and distributes the published guide.

## Fixed

- **Narrative tables** preserve cell and row boundaries in normalized opportunity text. ([#18](https://github.com/cyanheads/grantsgov-mcp-server/issues/18))
- **Agency prose** renders literal Markdown punctuation on the text response surface. ([#19](https://github.com/cyanheads/grantsgov-mcp-server/issues/19))
- **Search pages** reject malformed rows, counts, and unusable retrieval IDs while preserving supported sparse and empty responses. ([#20](https://github.com/cyanheads/grantsgov-mcp-server/issues/20))
- **Reference cache** discloses stale status, sanitized refresh failure, and retry time on both response surfaces; cancelling one waiter leaves the shared build available to others. ([#21](https://github.com/cyanheads/grantsgov-mcp-server/issues/21))
- **List inputs** report retained members' domain constraints rather than blank-padding regex errors. ([#22](https://github.com/cyanheads/grantsgov-mcp-server/issues/22))
- **Closing-window search** distinguishes exact counts from lower bounds at the scan ceiling, discloses incomplete empty pages, and bounds sequential pages by one operation deadline. ([#24](https://github.com/cyanheads/grantsgov-mcp-server/issues/24))

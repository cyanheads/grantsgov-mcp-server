# 0.2.1 — 2026-11-25

## Added

- **`grantsgov_search_opportunities`** accepts `include_narrative_eligibility` (default `false`): with `eligibilities` set, it also sends code `25` ("Others", eligible applicant types given in the eligibility narrative), the most common applicant-type code. `applied_filters.include_narrative_eligibility` is echoed only when `true`, and an empty search that did not send `25` adds a hint to set it. ([#26](https://github.com/cyanheads/grantsgov-mcp-server/issues/26))

## Changed

- **Failed Grants.gov HTTP responses** no longer carry the upstream response body in the error `data`.
- **`rate_limited` errors** name the retry-after seconds in their text.
- **A string `limit` above its maximum** is rejected with the range check instead of a type error.
- **`initialize`** reports the server description.

## Fixed

- **The empty-search hint to set `include_unrestricted`** no longer appears when code `99` was already sent. ([#26](https://github.com/cyanheads/grantsgov-mcp-server/issues/26))
- **The `include_unrestricted` description and `docs/design.md`** no longer call code `99` disjoint from the specific applicant-type codes. ([#26](https://github.com/cyanheads/grantsgov-mcp-server/issues/26))
- **Installed in a project's `node_modules` and launched from that project's root,** the server starts and serves `skill://grantsgov-guide/SKILL.md`; 0.2.0 exited at startup there because the relative skills folder resolved against the working directory.

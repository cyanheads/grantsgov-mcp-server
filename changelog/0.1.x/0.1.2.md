# 0.1.2 — 2026-10-08

Advertised tool schemas (`tools/list`) are byte-identical to 0.1.1.

## Added

- **Public hosted instance** at `https://grantsgov.caseyjhand.com/mcp` — a README section and a `streamable-http` remote in `server.json`.
- **Request IDs on tool errors** — error results end with `request <id>` and carry `data.requestId` ([cyanheads/mcp-ts-core#576](https://github.com/cyanheads/mcp-ts-core/issues/576), mcp-ts-core 0.13.10).
- **`.mcpbignore`** excludes `docs/idea.md`, `logs/`, `.cache/`, and `tests/` from the `.mcpb` bundle.

## Changed

- **Session mode** — the server declares `sessionMode: 'stateless'` in source, so an HTTP run with `MCP_SESSION_MODE` unset serves stateless (it resolved to stateful before); an explicit `MCP_SESSION_MODE` still overrides. The Docker image already set stateless.
- **Error data** no longer carries server stack traces (0.13.7), request context (0.13.8), or `rootCause` (0.13.13).
- **Argument repair** — a string boolean (`"false"`) for a boolean field and `null` at an optional key are repaired before validation (0.13.14).
- **Client log notifications** from `ctx.log` honor `MCP_LOG_LEVEL` and mask sensitive fields (0.13.11).
- **Recovery hints** — declared hints are filled by the framework (0.13.10), so tool and service throws no longer forward them by hand. When a shared reference-snapshot build fails, each waiting tool still gets its own tool-named hint; the hint text callers see is unchanged.
- **`server.json`** npm entries drop the `run start:stdio` / `run start:http` arguments and use `runtimeHint: "npx"` (was `"bun"` with those arguments); the HTTP entry sets `MCP_TRANSPORT_TYPE` to `http` ([cyanheads/mcp-ts-core#622](https://github.com/cyanheads/mcp-ts-core/issues/622), 0.13.11).
- **Docker image** installs production dependencies in a `deps` stage on the build platform, so no Bun runs under QEMU (0.13.10), and prunes musl-only packages (0.13.11). Bun 1.4.0 → 1.4.2; `MCP_FORCE_CONSOLE_LOGGING` is no longer set.
- **Ignore files** — `.dockerignore` and `.gitignore` cover every `.env*` file (`.gitignore` keeps `.env.example`, `.env.template`, `.env.sample`); `.dockerignore` also covers the MCP Registry token files; `coverage/coverage-final.json` is no longer un-ignored.
- **`package.json`** — `packageManager` is `bun@1.4.2`, and `files` excludes `dist/*.mcpb` from the npm tarball.
- **CodeQL workflow** runs one job per language (`actions`, `javascript-typescript`), each uploading under `/language:<language>`.
- **Framework sync** — `framework-skills/`, `scripts/` (`devcheck`, `lint-mcp`, `lint-packaging`, `check-skill-versions`, `check-framework-antipatterns`, `release-github`; new `install-otel` and `prune-musl-packages`), and `.env.example` re-synced with mcp-ts-core 0.13.14.
- **Docs** — README, `CLAUDE.md`/`AGENTS.md`, and `docs/design.md` describe the hosted endpoint, framework-filled recovery hints, request IDs, and the source-declared session mode.

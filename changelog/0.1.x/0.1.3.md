# 0.1.3 — 2026-10-18

## Changed

- **List inputs** accept a whole string or an array, preserving normalization and blank-as-unset behavior ([#7](https://github.com/cyanheads/grantsgov-mcp-server/issues/7)).
- **Bounded reads** accept up to 50 nonblank identifiers per list and 50 unique identifiers combined, process five, and return executable continuations for deferred inputs; search accepts limits through 1,000 while returning at most 100 rows with clamp guidance ([#14](https://github.com/cyanheads/grantsgov-mcp-server/issues/14)).
- **Runtime and development references** align with Bun 1.4.3 and mcp-ts-core 0.13.15.

## Fixed

- **Narrative conversion** preserves text after alternate comment terminators, converts entity-encoded HTML, and discards incomplete recognized tags while retaining comparisons, source newlines and non-HTML angle text ([#6](https://github.com/cyanheads/grantsgov-mcp-server/issues/6), [#10](https://github.com/cyanheads/grantsgov-mcp-server/issues/10)).
- **Human-readable fields** receive bounded HTML5 entity decoding across search, detail and reference output; rendered identifiers and additional-information links preserve literal values ([#9](https://github.com/cyanheads/grantsgov-mcp-server/issues/9)).
- **Detail retrieval** exposes independent offsets, full totals and executable continuations for every capped list and narrative; attachments retain upstream creation timestamps ([#11](https://github.com/cyanheads/grantsgov-mcp-server/issues/11)).
- **Sub-agency facets** aggregate current-query subtree counts, including matching intermediate parents, without substituting cached global counts ([#12](https://github.com/cyanheads/grantsgov-mcp-server/issues/12)).
- **Latest revisions** include the active synopsis or forecast's note and changed public field names when listed; unknown names retain an `upstream:` prefix ([#13](https://github.com/cyanheads/grantsgov-mcp-server/issues/13)).
- **Table rendering** escapes delimiters in bounded forward work while retaining existing prose-table output ([#16](https://github.com/cyanheads/grantsgov-mcp-server/issues/16)).

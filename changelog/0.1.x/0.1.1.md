# 0.1.1 — 2026-09-24

First public release, built on the keyless Grants.gov REST API (`search2`, `fetchOpportunity`). No API key or server configuration.

## Added

- **`grantsgov_search_opportunities`** — search by keyword, agency, applicant eligibility, funding category and instrument, assistance listing, opportunity number, `posted_within_days`, or `closing_within_days`. Forecasted and posted by default; rows lead with `close_date_kind` and `days_until_close`, plus facet counts and offset paging up to 100 rows.
- **`grantsgov_get_opportunity`** — full records for up to 5 opportunities by id or opportunity number: award range, eligibility codes and narrative, key dates, assistance listings, contact, and attachments with download URLs. Misses and shared numbers come back in `unresolved[]` as `not_found` or `ambiguous`.
- **`grantsgov_list_reference`** — agency, eligibility, funding category, and funding instrument codes from a live snapshot cached 24 hours, with open and total counts, plus statuses, sort options, and keyword syntax. An agency's counts cover its whole subtree ([#3](https://github.com/cyanheads/grantsgov-mcp-server/issues/3)).
- **Keyword compilation** — bare terms are joined with `AND` and tokens like `COVID-19` or `93.866` are quoted as phrases. An ungrouped AND/OR mix ([#1](https://github.com/cyanheads/grantsgov-mcp-server/issues/1)) or a `field:value` prefix ([#2](https://github.com/cyanheads/grantsgov-mcp-server/issues/2)) fails as `invalid_keyword` with a hint naming the fix.
- **Filter mapping** — agency codes expand to their sub-agency subtree, opportunity numbers match literally, and unknown codes fail as `unknown_agency`, `unknown_eligibility`, or `unknown_funding_category`.
- **Deadlines** — counted from today in US Eastern Time; `closing_within_days` scans posted opportunities by close date (up to 2,000 rows), and far-future stand-in close dates are flagged `placeholder`.
- **Empty-result notices** name the next call; a zero-hit `assistance_listing` search points to checking the ALN or searching the program name ([#4](https://github.com/cyanheads/grantsgov-mcp-server/issues/4)).
- **Upstream failures** surface as `upstream_unavailable`, `rate_limited`, or `upstream_route_unavailable`, after retries, with at most 4 concurrent Grants.gov requests per process.
- **Agency text handling** — HTML becomes plain text; in `content[]`, inline text is flattened across every Unicode line break and multi-line fields render as blockquotes. Input patterns and HTML conversion run in linear time.
- **Distribution** — npm `@cyanheads/grantsgov-mcp-server`, the MCP Registry, a `.mcpb` bundle for Claude Desktop, `ghcr.io/cyanheads/grantsgov-mcp-server`, and Claude Code and Codex plugin manifests.
